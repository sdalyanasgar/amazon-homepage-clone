# 🛒 Amazon Homepage Clone

A frontend clone of the Amazon homepage built using **HTML5 and CSS3**. This project recreates the basic layout and visual appearance of Amazon's homepage as part of my frontend web development learning journey.

## 🌐 Project Overview

This project is a static Amazon-inspired shopping homepage featuring a navigation bar, search section, promotional banner, product categories, and footer.

The main goal was to practice HTML structure, CSS styling, Flexbox, layouts, and working with images.

## ✨ Features

- **Navigation Bar** – Amazon-style header with logo, delivery location, search bar, account section, orders, and cart.
- **Search Section** – Search input with category selection and search icon.
- **Navigation Panel** – Quick links for Today's Deals, Customer Service, Registry, Gift Cards, and Sell.
- **Hero Section** – Large promotional banner with a message.
- **Product Categories** – Eight shopping category cards with images:
  - Clothes
  - Health & Personal Care
  - Furniture
  - Electronics
  - Beauty Picks
  - Pets Care
  - New Arrivals in Toys
  - Discover Fashion Trends
- **Footer Section** – Back to Top section and informational links.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
- Flexbox
- CSS Background Images

```bash

```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Explore the Amazon-inspired homepage!
